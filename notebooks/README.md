# Notebooks

The authoritative MSc analysis notebook will be added here when it is ready for portfolio publication.

## Publication checklist

Before committing the notebook:

- restart the kernel and run all cells from top to bottom;
- remove exploratory dead ends that are no longer part of the final analysis;
- keep enough intermediate validation output to make the data pipeline auditable;
- ensure every chart has a clear analytical purpose;
- use consistent country names, units and time windows;
- document missing-data decisions explicitly;
- avoid claims that exceed the evidence shown by the source data;
- remove local file paths, credentials, tokens and private information;
- confirm that all public data sources are properly attributed;
- export a clean HTML version only after the notebook executes successfully.

The final notebook should tell a coherent story from **business/analytical question → data provenance → quality checks → transformation → analysis → visualisation → interpretation → limitations**.
